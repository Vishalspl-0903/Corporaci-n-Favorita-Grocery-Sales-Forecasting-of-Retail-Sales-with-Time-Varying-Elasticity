## Dataset Path Configuration

The dataset paths are configured in [backend/config.py](backend/config.py):

```python
# Base paths
BASE_DIR = os.path.dirname(os.path.abspath(__file__))  # backend/
ROOT_DIR = os.path.dirname(BASE_DIR)                    # BDA_TSA/
DATA_DIR = os.path.join(ROOT_DIR)                       # BDA_TSA/ (where CSVs are)

# Input data files (automatically point to root directory)
TRAIN_CSV = os.path.join(DATA_DIR, 'train.csv')        # BDA_TSA/train.csv
TEST_CSV = os.path.join(DATA_DIR, 'test.csv')          # BDA_TSA/test.csv
ITEMS_CSV = os.path.join(DATA_DIR, 'items.csv')        # BDA_TSA/items.csv
# ... and so on
```

**This means:**
- CSV files should be in the **root directory** (BDA_TSA/)
- Backend code is in **backend/** subdirectory
- Processed files go to **backend/data/processed/**
